# Vídeos modelo

Coloque aqui os vídeos de referência (.mp4/.mov) e rode:

```bash
python3 scripts/analisar-modelo.py modelos/arquivo.mp4
```

A análise fica em `modelos/arquivo/` (`ficha.md`, `quadros.png`, `onda.png`).
Os vídeos em si **não** vão para o git (podem ter direitos de terceiros); só as fichas.
